## Screens
Home (`/`) - landing, explains the widget
Widget (`/widget`) - lead capture form (name, email, message)
Leads Dashboard (`/leads`) - list of captured leads
Lead Detail (`/leads/[id]`) - single lead view
Settings (`/settings`) - configure widget fields/branding
Health check (`/health`) - fetches real data from own Firestore, renders it

## Data source
Firebase Firestore (own backend, no external API dependency)
